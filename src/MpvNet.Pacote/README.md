# MpvNet.Pacote

Projeto de empacotamento MSIX/WAP para distribuicao na Microsoft Store.

Use este projeto apenas em ambiente Windows com Desktop Bridge/MSIX instalado.
O pacote e o fluxo de publicacao sao x64-only; a solucao e os scripts devem ser
executados em `x64` para evitar referencia MSIL inconsistente.
