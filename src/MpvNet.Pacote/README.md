# MpvNet.Pacote

Projeto MSIX/WAP x64 para distribuição na Microsoft Store. Use Windows com
Desktop Bridge/MSIX instalado no Visual Studio e selecione `Release|x64`
para gerar o pacote de distribuição. Requisitos, assinatura e identidade
estão em [Empacotamento Microsoft Store](../../docs/developer/build-release.md#empacotamento-microsoft-store).
