# Política de segurança

## Versões suportadas

| Versão | Suporte de segurança |
| --- | --- |
| `main` | Sim |
| Versão mais recente publicada em Releases | Sim |
| Versões anteriores | Não garantido |

## Como denunciar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade em uma issue ou pull request
público.

Envie a descrição, os passos para reproduzir e o impacto para
[wanderson_souza@hotmail.com](mailto:wanderson_souza@hotmail.com). Se a opção
de denúncia privada estiver disponível na aba **Security and quality** do
GitHub, ela também pode ser usada.

Inclua somente as informações necessárias para reproduzir o problema e, quando
possível, uma sugestão de correção. Não envie senhas, tokens ou chaves reais.

O relato será analisado de forma responsável. Após a correção, a divulgação
pública será avaliada conforme o impacto e a disponibilidade de uma versão
corrigida.
